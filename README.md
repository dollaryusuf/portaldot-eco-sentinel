## 🌐 Project Overview
**Portaldot Eco-Sentinel** is an autonomous monitoring and governance layer built on the Portaldot Network. While traditional block explorers show "what" happened, Eco-Sentinel audits **"at what cost."** It bridges the gap between raw Substrate execution data and real-world environmental impact.

### 🍃 Mission Alignment
As Portaldot scales to support global digital interactions, **Eco-Sentinel** ensures the network remains **Green and Trusted** by:
1.  **Auditing Sustainability:** Converting block weight into Carbon Metrics.
2.  **Predicting Fatigue:** Using Linear Regression to forecast infrastructure stress.
3.  **Enforcing Governance:** Bridging audits directly into the LAO NPoS governance layer.

---

## ✨ Key Technical Features

### 🌍 Global Infrastructure Monitoring
A high-fidelity monitoring station that tracks validator clusters across the globe. Using a **DePIN Energy Oracle Feed**, the Sentinel monitors grid intensity in real-time, coloring node clusters based on their current carbon footprint.

### 🕵️‍♂️ Historical & Live Auditing
Leveraging the **Portaldot SearchExtension**, Sentinel performs deep-packet inspection of blocks.
- **Success/Failure Audit:** Identifies high-weight/low-fee anomalies.
- **Green Reputation Index:** Ranks the most efficient validators on the network.

### ⚖️ Autonomous Governance Bridge
When sustainability thresholds are breached, Eco-Sentinel initiates a **Multisig Flag Call**.
- **Consensus Required:** 2/3 Auditor approval.
- **Outcome:** Automated submission of governance referenda to the Portaldot democracy pallet.

## 🔌 Portaldot SDK Integration
Eco-Sentinel was built from the ground up using the **Portaldot Python SDK**:

| SDK Component | Implementation in Sentinel |
| :--- | :--- |
| `PortaldotInterface` | Real-time WebSocket subscription to block headers. |
| `retrieve_extrinsic_by_identifier` | Extracting `weight` and `fee_amount` for audit streams. |
| `compose_call` | Building the "Green-init" and "Sust-audit" batch remarks. |
| `create_multisig_extrinsic` | Coordinating the Auditor Consensus for flag calls. |
| `get_payment_info` | Powering the real-time Carbon Intensity Estimator. |
